1.1 Subcellular proteomics

The field of subcellular spatial proteomics is centered on the determination of protein localisation within the cell. Importantly, protein localisation is intimately linked to protein function and is vital for research into basic biological mechanisms impacting the health and disease of all organisms (Sigaeva et al. 2026).

Quantitative mass spectrometry (MS)-based proteomics methods have been developed to study protein localisation at the proteome-wide level and generate subcellular “maps”. Several high throughput MS-based correlation profiling methods have been established and include the Localisation of Organelle Proteins (LOP) family of methods (Sadowski et al. 2006; Geladaki et al. 2019; Christoforou et al. 2016; McCaskie et al. 2025), dynamic organellar maps (DOMs) (Itzhak et al. 2016), protein correlation profiling (PCP) (Foster et al. 2006), sequential detergent-based solubilisation (Martinez-Val et al. 2021), COLA (Mardakheh et al. 2017), Prolocate (Jadot et al. 2017) and SubcellBarCode (Orre et al. 2019). Despite subtle differences in experimental design, as summarised in the figure below, all of these methods generate a similar data matrix (PSM, peptide or protein abundance across fractions) and can be analysed using the same subcellular proteomics software.

Generation of correlation profiling data requires considerable effort, expense and well thought-out experimental designs for successful implementation. Equally, data analysis involves considerable time and investment to produce high quality, robust datasets which enable meaningful biological interpretation and utility to the research community.

In this course material, we provide an updated workflow for the processing and analysis of correlation profiling-based spatial proteomics data, based on our F1000 workflow (Hutchings et al. 2025). We cover the key steps required to extract spatial information from quantitative correlation profiling MS data. The first step requires data importation, processing, and quality control followed by the definition of subcellular markers. We discuss how to curate such markers using approaches including unsupervised clustering and dimensionality reduction. Next, we show how to use subcellular markers to generate spatial proteome maps. This involves the classification of protein localisation through classical or Bayesian semi-supervised machine learning algorithms using the pRoloc package.

1.2 Software

In this workflow we use R packages from Bioconductor, namely, the QFeatures package for upstream data processing and the pRoloc for downstream machine learning.

NoteMSnSets versus QFeatures data structures

In our first F1000 workflow for spatial proteomics (Breckels et al. 2018) we used the MSnbase package and the MSnSet infrastructure for storing and manipulating our spatial proteomics data. In this workflow, we have transitioned to working with the QFeatures package for data processing. Whilst MSnbase provides functionality for manipulating and storing quantitative proteomics data, the QFeatures infrastructure makes it possible to store all levels of the data together in one object with explicit links maintained between hierarchical levels. For example, it is possible to store the peptide spectrum matches (PSMs), peptides and proteins (among other types of data) derived from all replicates of an experiment together, in one single data container.

1.3 The use-case: Subcellular mapping of U-2 OS cells

As a use-case, we will analyse a label-free DIA subcellular proteomics dataset from a partially differentiated human osteosarcoma (OS) cell line (U-2 OS cells) (McCaskie et al. 2025). U-2 OS cells are one of the earliest described cancer derived cell lines and have been applied across many areas of research. For subcellular proteomics they have been widely used in benchmarking as they provide a robust, flat, epithelial-like morphology and a deeply profiled human proteomic reference map.

Mass spectrometry (MS)-based protein correlation profiling data can be generated using a number of methodologies. These methods can differ with respect to (1) biochemical fractionation, (2) peptide quantitation (label-based or label-free), and (3) mass spectrometry acquisition method (data-dependent acquisition, DDA, or data-independent acquisition, DIA).

Our use-case data (\(\ref{fig-use-case}\)) was generated using the DIA-LOP method from the Lilley lab at the Universisty of Cambridge. DIA-LOP (Data-Independent Acquisition Localization of Organelle Proteins) is a high throughput subcellular proteomics method that offers a faster, label-free, and cost-effective alternative to classic multiplexed LOPIT methods (McCaskie et al. 2025). The pipeline works by gently lysing cells and using differential ultracentrifugation to separate intact organelles into 10 distinct fractions based on density. Instead of using expensive chemical tags e.g. tandem mass tags (TMT), these fractions undergo label-free peptide digestion and are analyzed via advanced DIA mass spectrometry, which systematically fragments all ions to capture low-abundance proteins from very low sample inputs. For each fraction, a total of 750 ng of peptide was analysed using using a timsTOF HT mass spectrometer (Bruker Daltonics, Bremen, Germany) coupled with a nanoElute 2 UHPLC system (Bruker Daltonics).

For the paper, the data was processed using the freely available DIA-NN software (v 1.8.2 beta 27) (Demichev et al. 2019) for peptide and protein identification and quantification, followed by the Bioconductor QFeatures package to aggregate and process precursor-level data into robust protein abundance profiles. Subsequently, the pRoloc package was used for protein subcellular localisation and the generation of subcellular maps, matching the abundance profiles of unknown proteins against known organelle markers to map over 8,000 protein groups across 13 subcellular compartments. The raw MS data is available online through ProteomeXchange via the PRIDE repository under the identifier PXD063082.

NoteIdentification search of the raw MS data

Database searching of MS data involves comparing the observed MS spectra to expected MS spectra generated via in silico digestion of a selected protein database. Since the use-case data used human cells, we provided the SwissProt human proteome to DIA-NN as the database for searching. We also provided a database of common contaminants that could be present in our sample due to (i) human contamination (e.g., keratin from nails, hair or skin), or (ii) sample preparation (e.g., enzymes used for protein digestion). These two databases are can be found in the course materials and also here.

The result of such a database search is a list of peptide spectrum matches (PSMs), or precursors, that is a list of matches between observed and expected spectra. Most software will also aggregate the PSM or precursor level data upward and provide output files at all data levels (PSM/precursor, peptide and protein). It is up to the user which output file to use for further analysis.

The starting point for this workshop and data processing workflow in R is an output file from the identification search. Different softwares output different file formats, for example the Proteome Discoverer v3.0 (Thermo Fisher Scientific) outputs a .txt file format, as does MaxQuant, FragPipe, other such as DIA-NN output parquet formats, will will show in the subsequent section how to import such data. Of note, the data was reprocessed using DIA-NN v2.0 (Academia) meaning that the files are no longer the exact ones used by (McCaskie et al. 2025).

1.4 Which data level should you start from?

Proteomics search and quantification software can report results at several levels: PSMs, precursors (a peptide sequence with its modifications and charge state), modified peptides, peptide sequences, and protein groups. In general, we recommend starting from the lowest level available. This gives you maximum control over data quality filtering, normalisation and aggregation, and makes each step of the analysis easier to understand and report transparently.

What “lowest level” means depends on the acquisition method. For TMT data acquired by DDA, each MS2 spectrum is matched to a peptide, so analysis can start from the PSM level. In DIA, MS2 spectra are chimeric and identification is peptide-centric, so there are no PSMs and the lowest level is the precursor. Some tools for label-free data also only accept peptide-level input, so starting at the lowest level is not always possible.

The data we will use in this workshop is label-free DIA-LOP, so we will start from the precursor level (rather than the PSM-level TMT data typical of DDA LOPIT). The data was reprocessed using DIA-NN v2.0 (Academia) meaning that the files are no longer the exact ones used by (McCaskie et al. 2025).

1.5 Summary

The use-case data that we will process and analyse in this workshop is a DIA label-free LOP subcellular proteomics dataset on human U-2 OS cells. The aim of the experiment is to determine where proteins reside in the cell (their subcellular localisation).
